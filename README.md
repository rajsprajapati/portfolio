# Raj Prajapati Portfolio

A modern personal portfolio website built with React and Vite.

## Features
- Modern dark-themed portfolio design
- Responsive layout for desktop and mobile
- Project showcase section
- Skills and experience presentation
- Contact information with direct links
- Downloadable resume text file

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

## Project includes
- Hero section
- About section
- Skills section
- Projects section
- Experience section
- Education and growth section
- Service offerings
- Contact section
- Resume button
